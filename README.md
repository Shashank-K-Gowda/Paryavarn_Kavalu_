Paryavaran-Kavalu

Paryavaran-Kavalu is a geo-tagging based environmental monitoring Android application developed using Kotlin, Jetpack Compose, Firebase Firestore, and Google Maps API. The application helps citizens report illegal waste dumping locations and enables cleaners or volunteers to monitor and update cleanup activities in real time.

The project focuses on improving environmental cleanliness, public participation, and efficient waste management through modern Android technologies and cloud-connected services.

GPS-based location capture
Real-time Google Maps visualization

Project Workflow
User opens the application
User selects Citizen or Cleaner role
Citizen reports waste using image and GPS location
Report data is stored in Firebase Firestore
Waste locations are displayed on Google Maps
Cleaner monitors reports and updates cleanup status
Updated status is synchronized in real time
